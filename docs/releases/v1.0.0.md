# Prism Station v1.0.0 发布说明

日期：2026-08-12
分支：`develop`
落地计划：`docs/plans/one-person-enterprise-refactor.md`（候选池已全部完成）

## 发布定位

Prism Station v1.0.0 是「一人公司产品生命周期」闭环的首个可用版本：CPO（用户）提出构想 → AI Studio 用 The Agency 专业 Agent 组队做两轮论证 → 固化为七区块旅程文档 → Actions 派发本地 CLI 实现 → 四级验证矩阵把关 → 手动归档回 Knowledge → 新建/挂载项目时检索旧旅程并注入论证上下文。

## 核心功能

### 💬 AI Studio（需求论证 Canvas）

- 255 个 The Agency Agent 目录，17 个 Division 筛选 + 关键词搜索。
- 5 个内置团队预设 + 自定义团队预设保存。
- 两轮论证：第一轮并行独立发言，第二轮 MOA 共识汇总（分歧/共识/风险/结论）。
- 「固化为旅程文档」：写入项目 `docs/journey/<slug>.md`，`journeyStage: discussing → ready`。
- 挂载项目后自动检索相关历史旅程并注入 system 上下文。

### 🎯 Actions（交付终端）

- CLI 自动识别：PATH 探测 `claude / aider / codex / gemini / opencode / qwen / cursor / windsurf`，选择器只展示已检测 CLI，移除 Prism CLI。
- 任务挂旅程文档：命令模板引用 `journeyDocPath`，不再硬编码 `sprint-8.md`。
- `v` 键四级验证：
  - L1 静态类型与编译（tsc / eslint / cargo check / clippy）
  - L2 单元与契约测试（cargo test / npm run build）
  - L3 无头浏览器与视觉验真（preview-verify + CDP 断言）
  - L4 AI DoD 语义对齐与安全审计（git diff 硬编码密钥/调试输出扫描 + MOA 审查摘要）
- 验证失败一键自动修复，最多 2 轮，每轮人工确认。

### 📚 Knowledge（活体知识库）

- 语义搜索（⌘K / `/`）+ 类型过滤 + 卡片/拓扑图视图。
- 归档旅程卡片 `📚` 标记并豁免活性衰减；一键重新打开项目。
- Obsidian 联动与注入 Studio Context。

### 📁 Projects / 📊 Dashboard

- 项目旅程阶段（idea → discussing → ready → building → archived）管理。
- 挂载到 Studio、归档旅程、重新打开。
- 今日焦点、阻塞告警、AI 风险推送。

## 技术栈

- 前端：React 19 + Vite 7 + Tailwind CSS 4 + Zustand。
- 桌面：Tauri 2（Rust 后端，SQLite，浏览器 fallback 同构）。
- 数据：`agent_catalog` / `team_presets` / `cli_tools` 表 + 双端 fallback。

## 运行方式

```bash
npm install
npm run dev          # 浏览器模式 localhost:1420
npm run tauri dev    # 桌面模式
```

Windows 桌面构建前需要把 Rust toolchain bin 加入 PATH：

```powershell
$env:PATH = "C:\Users\Shing\.rustup\toolchains\stable-x86_64-pc-windows-msvc\bin;$env:PATH"
npm run tauri build -- --debug --no-bundle
```

## 已知限制

- 浏览器 fallback 无法真正扫描 PATH，CLI 探测为「claude/aider 可用 + 合并历史结果」的模拟；真实探测只在 Tauri 桌面端生效。
- L4 的完整 Agency QA/CISO 语义审查依赖 AI Provider 配置；`verify:matrix` 以 MOCK 静态规则降级执行。
- `verify:ui` 需先启动 dev server；CI 建议使用 `verify:preview` 或 `verify:matrix`。
- 用户本地脏文件（`package.json`、`src/lib/searchHistory.ts`、`src/lib/tokenBudget.ts`、`src-tauri/Cargo.toml`）未纳入提交范围。
