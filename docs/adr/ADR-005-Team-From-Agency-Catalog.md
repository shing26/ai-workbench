# ADR-005: Team Composition from The Agency Catalog（Agent 团队来源）

用户组建讨论团队时直接使用 The Agency（`github.com/msitarzewski/agency-agents`，MIT）目录中的专业 Agent；工作台导入其 frontmatter 与精简后的 developer instructions 作为 Studio 的可选团队成员，不再自建部门、员工编制或组织架构。本决策取代 ADR-002。

**Considered Options**: 自建部门 + 员工 CRUD 组织架构（企业化、维护重且易沦为演示）；内置少量精选 Agent（扩展性弱、无法“组建理想团队”）。
