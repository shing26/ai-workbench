# ADR-001 全量正文

本笔记镜像 `docs/adr/ADR-001-Local-MoA-Orchestrator.md`，供 Obsidian 内阅读。以仓库 MD 文件为权威源。

## 背景

v1.0 已交付 5 大主视图，8 项质量门全绿。双代理 UX 审查确认 v1.0 是"功能堆砌但摩擦高"：任务只增不减、草稿切视图即丢、MOA 浏览器死锁、破坏性批量操作无确认。本轮为下一迭代确立定位与架构方向：个人本地 MoA 编排层。

## 1. 产品定位（4 维）

- 核心价值：Solo Creator 的"个体能力放大器"，定位是指导下一阶段的目标态。
- 产品形态：LUI 优先统一入口，AppDock 退居二线。
- 目标用户：主战场 Solo Creator，员工叙事降级为"未来可借鉴"。
- 业务边界：本地粘合剂，HITL 关键决策权在人，确认门 Rust 层强制。

## 2. 架构形态

本地桌面优先，不重写 FastAPI 服务端。Tauri 壳保留，编排层为同进程 Rust 服务或本地 sidecar。状态在 SQLite/进程内，无云组件。浏览器 fallback 与 Rust 同构。

## 3. 统一入口（LUI 优先）

删除死代码（Sidebar/TopBar/旧 CommandPalette/5 旧视图/8 旧 store）。CommandPalette 重写支持实体级搜索（笔记/项目/任务/动作），Ctrl+K 拉起，模糊匹配 + 最近使用排序。AppDock 只留高频导航。验收：80% 日常操作 3 次按键内完成。

## 4. 本地 Agent 名录

codex_agent（Codex CLI）、webhook_agent（定时/外部触发）、recap_agent（复盘）、document_agent（Markdown/双链）。编排引擎 = 决策层（做什么/顺序/状态），Automation/Connection Layer = 执行层（怎么触发/怎么连外部）。

## 5. 行为记忆

`user_behavior_memory` 表（id, signal_type, payload_json, created_at, confidence_score, is_active）。信号：显式反馈/隐式重复/偏好声明/时间模式。自动裁剪 confidence<0.3 且 30 天未触发。绝不自动改写 `user-profile.md`。

## 6. Router + FSM 状态边界

`fsm_nodes` 表逐节点持久化（status: pending/running/paused/blocked-on-human/complete/aborted）。重启断点复活，仅本机，不跨设备续跑。4 级降级（health→fallback→Ollama→离线提示），逻辑抽 `router-fsm.ts` 双端共用。澄清走 `clarification-guard` 中间件，LLM 出题、UI 可点选项，答完才执行。

## 7. Sub-Agent 生命周期与并发

全局 1 个 FSM 实例；单任务内 3 路 provider 并行。max_tokens 4096/请求；全局 TPM 60,000 超限排队。定时/Webhook 只在应用打开期间运行（不上自启），错过窗口启动自愈。

## 8. Evaluator + 零信任执行

Fail-Closed 默认：超时>30s/空输出/schema 失败/token>2048/敏感性失败 → failed 转 blocked-on-human。输出校验中间件必过。retry 绑 node_id，max 2 次 + 2s/8s 退避；provider 降级与澄清轮次不计 retry。

## 9. 授权与执行边界

`permission_rules` 表（subject/action/object/mode）。初始规则：doc read ~/notes/**=allow；codex exec **/*=ask；any delete **/*=deny（独立审批流）。确认门下沉 Rust Tauri 命令层（RequiresConfirmation / PermissionDenied）。敏感路径编译期白名单，不存在对应 IPC。

## 10. 幂等与去重

重试 = 同一条 delivery 重发，delivery_id(ULID) 不变。`UNIQUE(rule_id, event_id)` + INSERT OR IGNORE。三入口收敛 `enqueue_delivery`。审计记录"尝试入队但被忽略"。

## 11. 可观测性

FSM run 创建时 Rust 生成 ULID trace，贯通 fsm_nodes/provider/error_logs/webhook/run_metrics。`run_metrics` 表（run_id, trace_id, kind, started_at, ended_at, node_count, hitl_count, total_tokens, status）。`MOCK_ALL_AGENTS` 开关离线跑全流程。

## 12. 成本与合规

前缀缓存（Provider Prompt Caching）+ 条件校验（仅 write/exec/delete/outbound 跑完整校验）+ TPM 门控。被遗忘权：强级联物理删 messages/fsm_nodes/run_metrics/error_logs；sync snapshot/vault 索引/投递日志/user_behavior_memory 走自然过期或软删。密钥只进 Keyring，context_json 只存 keyring_ref。
